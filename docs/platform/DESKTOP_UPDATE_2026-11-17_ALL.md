# Matcha 合版更新 · 2026-11-17

关闭旧版 Matcha，再从桌面「Matcha」打开本次新版。配置、Mod 库和方案草稿沿用原位置。

## 助手打开就绪，Mod 整理更完整

- Pi 随 Matcha 一起打包，打开后在后台自动连接。设置里可管理服务商密钥、自定义模型端点、默认模型与思考强度，以及自动压缩和重试。
- 支持会话列表、删除会话、手动压缩和平台工具清单。
- 内置 Mod 整理技能：查看 VPK 资源与配置、比较内容、分类和收藏、维护分类、搜索与下载工坊 / GameMaps 内容、导入网页下载、解包、重试与取消任务，以及加入已有方案草稿。
- 整理记录保存最近 100 次，重开后仍可查询、撤销。删除会先列出影响并确认，文件进入 Matcha 回收站，支持还原；永久删除单独确认。

## 下载过程看得清

- 下载页显示实时速度、剩余时间、字节进度、排队顺序、卡住提示、最近一分钟速度曲线与完成统计，支持批量重试失败项。
- 内置浏览器下载约每 200 毫秒回报字节进度。已知大小时显示百分比；未知大小时显示未定进度。Windows 任务栏同步显示下载进度。

## 浏览与社区加速

- GameMaps 地图 / Mod 浏览、分类、排序、详情与下载；下载后解出 VPK，进入「新下载」并默认停用。B 站支持匿名搜索与详情。
- Steam++ 社区加速随包提供。工坊封面与内置工坊网页共用加速开关；关闭后恢复原入口。首次开启所需的证书与 hosts 授权，以及恢复方法，见 [社区加速](COMMUNITY_ACCELERATION.md)。

## 游戏设置与本机组件

- 游戏启动与 autoexec 设置归到「设置」，首页可直达启动设置；发射前先保存待提交的设置。
- 启动方式收为「纯净对抗」与「L4N 平台启动」。L4N 平台启动默认参数为 `-steam -novid -vulkan`，沿用游戏默认安全模式。
- 合并轻量 DLL 加载器、游戏内设置抽屉、物资雷达 1.5.9、L4N 2.58.0 与 DXVK 3.1.1。DLL 页展示配置状态与运行时观测，Matcha 插件和 L4N 子插件分开管理。

## DLL 来源与展示资料

- 可通过助手从本地包、GitHub 和创意工坊读取来源资料，检查 SDK 包、暂存整理其余包、列出缺失项，再确认导入。
- Agent 补充资料单独保存并注明依据；作者已填写的资料保留，玩家可在详情页编辑资料。
- 记录来源版本与更新检查结果；详情页可读取包内声明的图片，支持图集、步骤和前后对比等内容块。

专用的 SDK ZIP 选择入口与缺文件提示仍待 Claude 接入，当前可交给助手整理。GitHub 公共 API 达到匿名限额时，等额度恢复后由助手重试；工坊来源已完成实读。
