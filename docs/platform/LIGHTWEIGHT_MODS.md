# 轻量模组与物资雷达

在 **DLL 模组 → RagDoll 自制模组 → 战役 HUD → 物资雷达** 安装并启用。保持 Steam 登录，回到首页选择 **L4N 平台启动**。Matcha Runtime 和雷达加载后，在游戏里按 **Ctrl + F7 → 物资雷达**；用方向键选择和调节，Enter 确认，Esc 返回。

- **显示与数字**：图标不透明度、整体不透明度、距离、数量、高差、字体。
- **选择显示的物资 / 物品发光**：逐物资选择，调节发光颜色、距离和亮度。
- **位置编辑**：在本地地图选一个已开启项目。方向键移动，Shift 加快，Alt 自由移动，+ / - 缩放；Enter 保存，Esc 撤销。

Matcha 版 1.5.9 沿用原 1.5.8 的物资识别和 HUD，移除对 `-insecure` 的初始化要求，适用于本地战役、写实与生还者。设置独立写入 `bin/l4p/data/ragdoll.supply-radar/settings.ini`。沿用旧布局时，退出游戏后把 L4N 版原 `settings.ini` 复制到这里即可。停用或更新雷达会保留该目录。

## 选择启动方式

- **L4N 平台启动**：以选定目录运行游戏，基础参数为 `-steam -novid`，使用游戏默认安全模式。L4N 整包开关、DXVK 渲染后端与雷达启用列表分别管理。雷达随 Matcha Runtime 加载；可在运行时状态中查看本次会话结果。装载路径和后端选择详见 [DLL 与 L4N 整包](NATIVE_LIBRARIES.md)。
- **纯净对抗**：在 Matcha 选择 Steam 登记的原版游戏目录。以默认 D3D9 路径启动，跳过 Matcha 的 DLL、VPK 方案和自动写入配置。已部署 Matcha 的目录可在退出游戏后用 **DLL 模组 → 运行时 → 恢复原入口**；切回模组时，在同一处选择 **重新启用 DLL 运行时**。这两步保留模组文件、设置和启停列表。发现额外的加载 DLL 或已启用的附加内容时，Matcha 会点明具体项目，请确认后手动处理。

桌面的旧「模组直启」「开发模式」配置自动迁移为「L4N 平台启动」。游戏运行期间，退出后再改动 DLL 的安装与启停。
