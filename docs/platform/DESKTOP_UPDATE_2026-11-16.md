# 2026-11-17 桌面整合更新

## 最新桌面整合（2026-11-17）

- 网页下载接入原生字节进度，实时速度和剩余时间沿用下载页的新测速逻辑。任务栏权限和调用已接通，支持确定 / 未定进度与结束清除。
- 「设置 → 通用 → 社区加速」新增内置 Steam++ 3.2.0。默认关闭，首次启用确认本机证书和 hosts，随 Matcha 启停。详见 [社区加速](COMMUNITY_ACCELERATION.md)。
- 新版 Steam 封面域名接入同一加速开关：Matcha 工坊卡片与内置工坊网页的公开图片复用 Steam++ 图片线路，保留缩图参数，关闭加速后恢复原入口。
- 工坊列表向 Steam CDN 请求 320 × 200 小图，打开详情再读取较大的封面；离开的卡片会释放排队和网络请求。仍返回超大原图的条目在列表上提示「点开详情看大图」。
- GameMaps 已接入桌面列表、详情和下载通道；读取列表和详情时优先等待页面内容，GameMaps 沿用常规网络。详见 [GameMaps 接口](../gamemaps-backend.md)。
- 游戏设置与启动流程已接通：设置页集中管理启动参数和 Matcha 的 autoexec 段，首页提供「启动设置」入口；启动前保存最新改动。游戏运行时先保存配置，下一次启动再应用。详见 [游戏设置接口](../game-settings-backend.md)。
- B站搜索与详情已接入匿名后端，包含置顶评论、WBI 签名、限频、缓存和风控错误提示；资源链接由前端识别。桌面封面域名已放行。详见 [B站接口](../bilibili-backend.md)。
- 合并当前设置页、自定义端点表单、B站与工坊详情布局。
- Pi 后端、当前原生模块和依赖随此次构建一并打包。游戏目录和正在运行的旧版保持原状；桌面快捷方式更新到新的独立发行目录，旧发行目录保留用于回退。
