# DLL 导入与更新接通

关闭旧版 Matcha，打开本次文件夹里的 `Flare.exe`。桌面快捷方式暂沿用上一包；本轮自动切换入口受到执行策略拦截。

- 本地来源支持选择 SDK ZIP、DLL 或文件夹。标准 SDK 包检查后预览导入；结构有差异或缺文件时展示问题清单，可交给 Agent 整理。
- Agent 与本地 ZIP 入口共用导入计划。同 ID 已安装时显示新旧版本，确认后更新；保留配置、启停状态、独立游戏内设置和手动补充资料，旧包完整备份。首次导入默认停用。
- 确认期间版本或开关发生变化时，重新预览确认。文件操作继续在游戏退出后执行。
- 来源卡片支持检查并记录最新版本、查看发布说明；本地来源可选择新压缩包更新。资料编辑支持长度检查与清空后恢复原资料。

使用方法见 [轻量模组](LIGHTWEIGHT_MODS.md)；接口交接见 [DLL 来源接入](../dll-source-handoff.md)。
