# DLL 浏览：大合集 → 小合集 → 功能

在「DLL 模组」先选择大合集，再进入开发者组织的小合集。每个功能单独安装、启停；点击封面或名称进入独立详情页，阅读开发者写的说明和游戏内使用方法。

Skeeto 源码移植时采用过以下分组，同一功能可以出现在两个小合集中：

```text
Skeeto
  ├─ 视觉与声音
  │    ├─ 静态窗口准星
  │    ├─ 视角倾斜
  │    ├─ 分类音量（17 类声音）
  │    └─ 优化听声辨位（与待定联机功能共用同一开关）
  ├─ 个人档案
  │    └─ 生涯档案
  ├─ 配置与运行
  │    ├─ 过关自动执行 CFG
  │    └─ 客户端性能预设
  ├─ 本地实验室
  │    ├─ 本地画面参数
  │    └─ 本地调试
  └─ 待定联机功能
       ├─ 优化听声辨位
       └─ 减少画面干扰
```

大合集、小合集和功能各有自己的封面和介绍。移植进度仍按原来的联机影响分类记录。

## 桌面接口：读取封面

后端 `plugin-cover` 只读取该功能 manifest 声明的封面，返回 `{dataUrl}`：

- 大合集：`{id,kind:"catalog"}`
- 小合集：`{id,kind:"collection",collectionId:"skeeto.visuals"}`
- 功能：`{id,kind:"module"}`
- 旧单层合集：沿用 `{id,kind:"collection"}`

文件读取保留路径逐级检查与图片格式校验。未声明的小合集 ID 返回 `collection_missing`。

## 桌面接口：区分安装与加载

`snapshot.plugins` 是已安装功能，`availablePlugins` 是随桌面包提供、尚未安装的功能；同 ID 以已安装记录为准。合集与详情页使用同一份安装预览、开关和设置状态。`enabled` 表示下次启动的选择，`runtimeState` 表示当前进程的观测。游戏运行期间保留读取和已声明的运行时动作，包文件与启用列表的写入在退出后进行。
