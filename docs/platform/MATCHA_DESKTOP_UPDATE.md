# Matcha Launcher 1.0.3

- **给 Mod 起个好记的名字。** 右键选择「修改显示名…」，或点详情标题旁的铅笔。新名和原名都能搜到，随时可以恢复原名。VPK 文件名和游戏内名称保持原样。
- **一眼看出 GameMaps 哪些内容刚更新。** 地图和 Mod 的列表卡片会显示站点的「新」「更新」「已归档」和 Beta 标记。
- **「冲突」筛选回到了 Mod 页。** 直接查看当前方案里还有资源冲突待处理的 Mod。
- **识别迁移后的 Mod 目录。** 支持通过 Windows 目录链接搬到其他位置的 `addons` 和 `addons/workshop`。跨盘删除和同名替换仍需在资源管理器中处理。
- **启动项和渲染状态更清楚。** 可手动填写 `-insecure`，界面会提示 VAC 联机限制。主页按本次启动参数显示渲染入口，区分原生 D3D9、游戏自带的旧版 DXVK 和自行安装的 DXVK。

更新时先从系统托盘退出旧版，将 Windows x64 ZIP 完整解压到新文件夹，再运行 `Matcha.exe`。原有设置和启动方案会沿用。
