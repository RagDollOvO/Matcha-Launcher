# Matcha 桌面版

### 茶茶附件与游戏设置

把文件拖进茶茶对话，或点回形针选择多个文件。图片随消息发送，小文本附上正文；ZIP、VPK、DLL 及其他大文件附上本机路径，可交给茶茶的包检查工具。选择 DeepSeek 时，引导使用 V4.1 Flash。

首次引导列出 Matcha 启动参数和磁盘上的 autoexec.cfg 状态。在「设置 → 游戏配置」查看物资雷达已保存的数值；游戏里按 Ctrl + F7 调整后，点「重新读取」。随包菜单更名为「抹茶模组设置」，依赖 ID 沿用 flare.game-ui。

### 本机 L4N 与渲染检测

首次引导显示已安装的 L4N 与 DXVK 版本。已有 L4N 可以直接启动。Matcha 模组运行时改走 L4N 子插件接口；DXVK 只读检测，原有渲染文件保留。

在 **设置 → 外观 → 主页壁纸** 导入图片。三种窗口配色下，主页都显示同一张原图；以前导入的壁纸会自动沿用。

**窗口配色**可选「墨绿深色」「薄荷浅色」或「随壁纸」。前两种使用固定的绿色，第三种从主页壁纸取色，主窗口和独立助手会一起换色。

**界面字体**默认使用荆南麦圆体。点「导入字体…」可选择本机的 TTF、OTF、WOFF 或 WOFF2，马上在窗口和助手里预览。下拉框可切回默认字体、系统字体或上次导入的字体。

- **主页音乐**：在右上角「音效 → 主页音乐」开关 16 分钟的放松音乐。首次与主窗口交互后开始播放，到曲末自动循环；离开主页会暂停，返回时从原位置继续。
- **Steam 玩家卡**：主页显示本机 Steam 的昵称、缓存头像和登录状态。点头像可刷新，缺少头像时显示昵称首字。
- **助手改名「茶茶」**：点顶栏的茶茶按钮或按 Ctrl+K 打开。新窗口默认宽 420，拖动主窗口只更新茶茶的位置；调整主窗口高度时茶茶才对齐高度。收起后保留对话和草稿。想在主窗口里分栏，到「设置 → 启动器」切换。
- **玩家记忆**：告诉茶茶「记住：本地武器 Mod 按替换对象分类」，新会话也能沿用。说「改成按作者分类」或「忘掉这条」，茶茶会自己更新本机的 `MEMORY.md`。茶茶的名字和说话方式也写在这份记忆里，可以直接改。
- **名称与图标**：桌面入口、程序、顶栏和茶茶统一使用 Matcha 与同一角色图标。原有设置、会话和方案继续沿用。
- **设置**：关闭主窗口会缩到托盘，右键托盘图标选择「退出」结束程序；在「启动器」可设置开机启动，在「数据与重置」按类别清理缓存，在「外观」调整界面缩放和减弱动效。「关于」提供检查更新入口。
- **网页下载与作者**：从 B站视频或爱发电作品转去网盘下载，手动导入和茶茶导入都能保留识别到的作者页。下载卡片上的「直接点赞」只给 B站原视频点赞；需要登录时，登录后回到视频页。
- **Mod 管理**：页头显示 VPK 总数和启用数，重载和「设为启动方案」放在右侧。「全部 Mod」筛选栏下直接是卡片，新建分类在左栏。主页用 L4N 平台启动时自动应用所选方案。
- **发现**：创意工坊、B 站和 GameMaps 共用浅底、短搜索框和两行卡片标题。B 站封面左上显示新视频、分类和资源来源角标；GameMaps 在封面等待或暂不可用时显示地图占位。
- **服务器**：卡片更紧凑，地图和章节点移到服名下方，延迟和连接操作一同显示。有名单时可以从一行预览展开。已有服务器时，点右上「添加服务器」展开地址表单。
- **插件与游戏设置**：插件页把加载器、DXVK 和 L4N 整包放在运行环境栏；游戏配置分为「画面」「网络」「CFG 原文」。
- **组件按需下载**：L4N 和 DXVK 首次使用时下载。先校验到本机，再预览游戏文件变化并确认启用。
- **SDK 更新与 DLL 安全检查**：DLL 页可查新版、核对来源和签名；导入前列出敏感能力，命中拦截规则时保留原安装。茶茶也能解释同一份筛查结果。
- **L4N 子插件**：在「插件 → L4N 整包」里，`bin\neko\plugins` 中的每个 L4N 插件可以单独开关，也能导入新的 DLL（导入后默认停用）。开关前会列出要移动的文件，下次完整启动生效；上次操作没做完时，页面上有「恢复」。
