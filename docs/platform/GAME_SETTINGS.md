# 启动项和游戏配置

从「主页 → 启动设置」进入。L4N 平台启动和连接服务器默认使用 `-steam -novid`，L4N 和 DXVK 的开关保持原样。想确认参数，可以展开「更多启动项」；如果这里仍出现 `-vulkan`，请检查「自定义启动项」，可单独删掉这个参数。

可单独选择跳过开场动画（`-novid`）、启动时打开控制台（`-console`）和低血腥度（`-lv`）。帧率上限填 **150** 表示 150 FPS，填 **0** 表示不限帧，留空沿用游戏里的设置。

## 游戏配置按主题查看，同一个 CFG 随时可改

想改准星，在「游戏配置 → 画面」选择「准星」，即可查看静态青色准星示例。点「加入 CFG」使用示例；如果已有部分命令，点「补入缺项」即可保留原值。例如，你之前写了 `cl_crosshair_thickness 2`，补入颜色和透明度后，准星粗细仍是 **2**。

- **画面**：按对象分别查看队友、已重生特感、灵魂态特感、近处物品或远处物品的轮廓，RGB 各为 0–1；也可切换到准星。
- **网络**：集中查看帧率与网络信息的草稿值和示例。示例保留原有图表高度。
- **CFG 原文**：直接编辑完整草稿，包括旧版保存的偏好和手写命令。浏览前两个标签或查看示例时，草稿保持原样。

「写入游戏」只管理 `left4dead2/cfg/autoexec.cfg` 中 Matcha 标记的一段。关闭时保留启动器草稿；游戏运行中先保存草稿，下次 L4N 启动前应用。纯净对抗使用 Steam 原版启动参数，游戏仍会读取目录里已有的 CFG。
