# Matcha 内测版

在 Windows 10/11 x64 上先将 ZIP 完整解压，再双击同一目录里的 **Matcha.exe**。首次打开时在设置中确认 Left 4 Dead 2 的 Steam 安装目录；使用茶茶时，在「设置 → 茶茶」配置自己的模型。桌面窗口使用 Microsoft Edge WebView2 Runtime。

内测设置、茶茶会话和窗口偏好单独保存在 `%LOCALAPPDATA%\com.matcha.launcher.beta`。非系统盘的游戏默认使用 `left4dead2\.matcha-beta-data` 保存下载和缓存。首次打开会出现欢迎引导；已安装的游戏和 Mod 仍会从 Steam 和游戏目录中识别。

## 试一次真正的启停

1. 游戏退出后，打开 **DLL 模组**。已经安装 Skeeto 的机器会显示它的卡片；没有安装的测试电脑可以先测其他功能。
2. 关闭卡片右上角开关。「本地 DLL」应显示入口已暂存，再打开会恢复原入口。玩家配置继续保留。
3. 也可以告诉茶茶「停用 Skeeto」或「启用 Skeeto」。同一张卡片会跟着实际状态变化。
4. 从 Steam 进入游戏验证：启用时按 `[` 打开菜单。再次切换前先退出游戏。

要完整卸载，在模组详情点 **让茶茶卸载…**，核对包含自定义配置的清单并确认。清理完成后，卡片随游戏文件一起移除。仍在 Steam 订阅核心更新包时，请同时取消订阅。

其他平台可把作者说明和安装包交给茶茶。支持独立 VDF 入口，或作者专属 INI 中的 0/1 总开关；茶茶先展示具体文件供你确认，再登记到卡片。遇到入口占用，保留冲突文件并显示原因。

反馈时附上操作步骤、卡片状态与报错截图。点「设置 → 数据与重置 → 日志」右侧的文件夹可打开日志目录；「下载与缓存位置」右侧的文件夹用于更换位置。反馈里请遮住模型密钥。
