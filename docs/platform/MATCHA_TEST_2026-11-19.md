# Matcha · 11 月 19 日合并测试版

**Mod 导入**：新 Mod 默认加入当前启动方案。Mod 页拖入同名 VPK 或素材文件夹，可保留方案启停状态并替换旧文件；旧 VPK 及分卷会先备份。

**关闭到托盘**：主窗口点 × 或按 Alt+F4 收到系统托盘。单击 Matcha 图标恢复，右键选「退出」结束启动器。

**好友在玩**：登录 Steam，点窗口右上角茶茶左侧的好友图标查看头像、昵称和状态。入口数字是正在玩 L4D2 的好友人数；点带箭头的好友可展开服务器详情。点「加入」预览启动，点星标收藏。查看列表无需启动游戏。

**社区加速**：普通权限打开 Matcha 即可启用。点社区加速开关后，在 Windows 授权框确认 Steam++；取消会保持关闭。

**声音面板**：右上角三个开关使用轻木音，静音和关闭界面音效时保持安静。其余操作沿用各自的音效。

**页面文案**：精简设置、服务器和 DLL 模组总览的说明。DLL 卡片保留版本、加载状态和快捷键，完整介绍见详情。

**壁纸轮播**：在「设置 → 外观」开启「壁纸轮播」，可一次添加多张图片，或选「整个文件夹」导入其中的图片。选好轮播间隔后回到主页即可看图切换；也可以选择「每次打开」、随机顺序，或让「随壁纸」的界面配色跟着当前图片变化。

**数据与重置**：点「下载与缓存位置」右侧的文件夹，选择新位置，再确认搬移。点「设置和记录」「日志」「茶茶的配置」右侧的文件夹，直接在资源管理器中打开对应目录。

**平台卸载**：DLL 页只显示实际检测到的平台。退出游戏后，在平台详情点「让茶茶卸载…」，核对清单后可移除平台文件、专属配置及登记。仍订阅 Skeeto 核心更新包的测试者，请在 Steam 取消订阅，避免再次下载。

**Mod 显示名**：告诉茶茶「给 M60 加上 [武器] 前缀」或「把它恢复原名」。支持批量处理和撤销；名字只保存在 Matcha 中，原包和游戏内标题保持原样。Mod 页可用原名或新名搜索。

**首页 DLL 数字**：按所选启动模式统计 Matcha 模组、L4N 子插件和外来平台。每个已接入的外来平台算一项，有开关的平台按启停状态计数。鼠标停在数字上可看明细。

**本地 DLL**：安装 Skeeto 后，在「DLL 模组」按名称搜索或点开模组卡片。页面底部的「本地 DLL」列出其入口和模块，并区分文件已就位与本局已装载。接入其他作者的模组沿用右上角「添加」。

**一键启停**：卡片开关和茶茶的启停工具共用同一份状态。Skeeto 的启动入口可暂存并还原；其他模组可由茶茶登记作者的 INI 总开关或独立 VDF 入口。切换在游戏退出后进行，下次启动生效。

**茶茶的确认方式**：「设置 → 工具与权限 → 完全访问」可直接登记 DLL、在桌面或文档目录整理文本。茶茶可以在同一份暂存副本上查看 ZIP 内的说明和脚本。实际运行第三方安装器仍有确认；随时可切回「自主」或「每次都问」。

**动态壁纸**：主页可播放导入的动态壁纸；游戏运行时或开启减弱动效后显示封面帧。

**CFG 备份兼容**：首次修改已有的 autoexec.cfg 时保存 Matcha 备份；识别旧版 Flare 备份，沿用此前的恢复资料。
