# Pi 自动连接、Steam 封面与网页下载更新

## Pi 新增 Mod 整理技能

本次补齐 P1 / P2：查看完整包内资源并核实内容差异；收藏、已整理和分类维护；工坊/GameMaps 搜索、链接下载、任务重试/取消、网页 ZIP 导入与解包；把成功项加入已有方案草稿。

分类、收藏、分类维护和方案成员调整会保存最近 100 次记录，支持「撤销刚才那次整理」，重开 Matcha 后仍可查。撤销会显示逆向清单并检查后续修改，保留其他 Mod 与方案设置。

直接告诉助手「整理新下载的 Mod，按用途归类」「看看哪些 Mod 可以清理」「还原刚才删的 Mod」。内置 `matcha-mod-organizer` 技能会结合实际 VPK 目录与介绍判断用途，优先沿用已有分类；信息不足的条目保留待判断。

分类前显示变更清单。删除前显示文件、分卷、收藏和受影响方案，批准后移入 Matcha 回收站；支持还原分类与方案草稿。永久删除使用独立确认。游戏运行期间可保存分类，文件修改留到退出游戏后执行。

## Pi 在后台自动连接

打开 Matcha 后，Pi CLI 自动在后台连接，助手面板收起时同样有效。连接完成后直接使用；启动期间显示连接进度，失败时提供「重试连接」与设置入口。关闭、重开面板沿用当前连接和对话。

## 封面与工坊共用加速开关

在 **设置 → 通用 → 社区加速** 开启「Steam 社区」。Matcha 工坊卡片与内置工坊网页的新版 Steam 图片域名，现通过 Valve 兼容图片入口复用 Steam++ 线路。原图片路径、缩图参数和 HTTPS 校验保留；关闭加速后恢复原入口。

从旧版更新后，关闭旧 Matcha，再从桌面快捷方式打开新版。已打开的 Steam 网页可刷新后生效。首次授权与恢复方式见 [社区加速](COMMUNITY_ACCELERATION.md)。

工坊下载现在同时保存静态封面，Mod 库可离线显示；独立库、Steam 订阅目录和以工坊数字 ID 命名的本地导入 VPK，在卡片首次显示时自动补图。原 VPK 和已有本地封面保留，封面获取失败后可重新进入 Mod 页重试。

## Mod 导入兼容中文配置

修复 GBK 编码 `addonlist.txt` 中中文 Mod 文件名触发 `invalid_addonlist` 的问题。导入和应用方案支持 GBK/GB18030 原编码读写，已有启停配置保持原样。

## 网页下载显示字节进度

内置浏览器按下载任务返回已接收字节与总量，约每 200 毫秒更新，完成和失败时即时发送最终状态。下载页沿用实时速度与剩余时间；未知总大小时显示未定进度。Windows 任务栏进度权限与调用一并接入。

## 沿用当前 DLL 组件方案

本轮合并工作区最新的轻量加载器、本地 DLL、物资雷达、L4N 与 DXVK 接入。组件说明见 [L4N 与 DXVK](NATIVE_LIBRARIES.md) 和 [轻量模组与物资雷达](LIGHTWEIGHT_MODS.md)。
