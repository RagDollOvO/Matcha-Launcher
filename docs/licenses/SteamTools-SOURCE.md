# Steam++ / Watt Toolkit 3.2.0

Copyright the BeyondDimension / SteamTools contributors. The Steam++ component ships as a separate process, with executables and dependencies from the upstream Windows x64 portable archive. Matcha invokes the Accelerator module; unrelated optional modules are omitted. The upstream executable code is unchanged.

- [Official 3.2.0 release, release notes and archive checksum](https://github.com/BeyondDimension/SteamTools/releases/tag/3.2.0)
- [Exact corresponding source and build files at tag 3.2.0](https://github.com/BeyondDimension/SteamTools/tree/3.2.0)
- [Source archive](https://github.com/BeyondDimension/SteamTools/archive/refs/tags/3.2.0.zip)
- [GPL-3.0 license](SteamTools-LICENSE.txt)

To obtain the source tree with its pinned dependencies:

~~~sh
git clone --branch 3.2.0 --recurse-submodules https://github.com/BeyondDimension/SteamTools.git
~~~

The package manifest gives the original portable archive URL and checksum. User configurations, certificates and private keys are generated locally at runtime.
