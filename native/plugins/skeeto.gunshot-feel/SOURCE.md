# 枪声听感增强 0.1.0

GPL-3.0，原作者 regoists/Skeeto contributors。Skeeto 2.2.19，提交 `7a18b4988d089fdf6cc7e857560cf82a9609a32c`。来源 proxy 的 `GunFeel*`、`ClientUxLowAmmoPaintTick` 与 HUD 的武器分类。

保留四种音高 168/45/78/210、默认强度 55%、短尾 90 毫秒/58 音高/0.55 音量、120 毫秒路径匹配和步枪后备、8 毫秒采样/250 毫秒长停顿重置、换弹抑制及霰弹枪中断例外。声音分类器沿用分类音量模块的同一上游规则；采样缓冲区使用原子字节与序列检测，原始音量按值透传。

Source 0.4.0 的实体、声音、本地音频与资源互斥接口提供共享能力。与听声辨位的互斥以已持有资源为准，保留两个模块的保存设置；原作选择后自动关闭另一项的 UI 改为显示占用状态。脚本音效中的房间混响接入后，通过 `skeeto.gun-reverb` 资源声明启用状态，叠层自动乘 0.75。

完整构建输入在 source/，Windows x86 C++17，CMake 3.22+。实际游戏表现待实测。
